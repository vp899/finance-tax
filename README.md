# 财务报税系统

面向小规模纳税人的财务核算 + 报税辅助系统。
技术栈：**FastAPI + SQLite（后端） · Next.js + React + Tailwind CSS（前端）**。

## 功能总览

| 模块 | 功能 |
|---|---|
| 科目表管理 | 新增/编辑/添加下级/删除/**禁用**（单个+批量启用/禁用/删除）；字段含科目编码/名称/核算类型（资产·负债·权益·成本·损益）/计量单位/借贷方向/默认币种/数量核算/**辅助核算**（项目·客户·供应商·部门·员工·存货）；期初余额按**年.月**展示；**导入/导出科目表**、**导入/导出科目期初**（含原币/本位币/本年累计/辅助核算明细）；**数据清零** |
| 凭证管理 | 新增凭证（**智能补全**：科目编码/名称/拼音首字母、摘要历史）、查看/编辑/复制/**作废/恢复/删除**、凭证汇总表；停用科目禁止记账 |
| 账簿 | 总账、明细账、余额表、序时账、多栏账、试算平衡表；全部支持**按月 / 按年度 / 按起止区间**查询 |
| 财务报表 | 资产负债表、利润表、利润表季报、现金流量表、现金流量表季报；利润表/现金流量表支持**年度与区间口径**；成本类科目自动并入存货，任意自建科目均被报表覆盖 |
| 月末结转 | **18 步结转全流程 + 一键结转 + 结转配置**：结转销售成本、计提/发放工资、计提/发放全年一次性奖金、计提/发放劳务报酬、计提折旧、摊销无形资产、摊销待摊费用、免交增值税、计提税金、地方水利基金、印花税、工会经费、计提所得税、结转汇兑损益、结转本期损益、结转未分配利润；反结转（作废对应凭证，报表自动回退） |
| 结账 | 结账检查（试算平衡 → 无草稿凭证 → 本期损益结平）、反结账、强制结账 |
| 财税设置 | 小规模纳税人 / 2013 小企业会计准则、凭证类型、科目期初（**可修改**，带全年合并口径试算平衡校验）、计量单位、币种、科目现金流量对照表、固定资产/无形资产、**财务人员**（记账/审核/出纳/会计主管）、**小数位**（数量·单价 2 位补零、汇率最多 6 位）、**辅助核算全局开关** |
| 数据管理 | 所有账簿/报表导出 Excel（支持年度/区间）、Excel 凭证导入（带模板）、SQLite 单文件备份与恢复 |

## 快速启动

```bash
# 1. 后端（端口 8000）
cd backend
pip3 install -r requirements.txt
bash restart.sh          # 或 bash run.sh

# 2. 前端（端口 3000）
cd ../frontend
npm install
npm run dev              # 生产环境用 npm run build && npm run start
```

浏览器打开 <http://localhost:3000>。后端 API 文档：<http://localhost:8000/docs>。

跨主机部署时设置前端环境变量指向后端地址：

```bash
NEXT_PUBLIC_API_URL=http://your-host:8000 npm run build
```

## 正确性保证

- 凭证校验：借贷必须平衡、必须使用末级科目、金额两位小数、**数量最多 2 位小数、汇率最多 6 位小数**、停用科目禁止记账、结账期间锁定
- 试算平衡：期初 + 发生额全程保持 借方合计 = 贷方合计；试算覆盖**全部有发生额/期初的科目**（含历史直接记账的非末级科目），并提供不平衡差额定位
- 期初修改：按**全年合并口径**校验平衡（而非仅本次提交行），重复科目行/负数/借贷同列均拒绝；有期初余额的科目不能被删除，防止试算被破坏
- 报表勾稽恒等式：
  - 资产负债表 **资产 = 负债 + 所有者权益**（未分配利润自动并入未结转的本年损益，任何结转状态下都平衡）
  - 现金流量表 **期末现金 = 账面现金余额**
  - 利润表自动剔除结转损益凭证，结转后仍显示真实经营成果
- 结转安全：所有结转凭证均由借贷平衡校验把关；结平方向按科目余额方向（支持费用科目贷方余额如利息收入/汇兑损益）；汇兑损益重估幂等，重复执行自动跳过
- 跨年安全：期初余额按年度存放；新年度未录入期初时自动**锚定最近有期初的年度**连续累计，跨年区间查询期末余额与账簿一致

### 结转配置（一键结转）

【结转与结账】→【结转配置】可对 18 步结转逐项设置：启用/停用、执行顺序、金额来源（手工录入/自动计算/按上期金额）、默认金额、记账科目、税率/费率（城建/教育附加/地方教育附加/水利基金/工会经费/印花税/所得税）。
【一键结转】按配置顺序批量执行，金额为 0 或不适用的步骤自动跳过并给出原因，单步失败不影响其他步骤，执行结果逐项可查。

## 月末处理流程（推荐）

1. 录入本月全部凭证
2. 【结转与结账】→ 点【⚡ 一键结转】：按结转配置自动完成计提工资/发放工资、计提折旧、摊销无形资产、计提税金、工会经费、计提所得税、结转本期损益等全部步骤（可在弹窗中逐项调整金额、取消勾选）
3. 如需单独处理：点击对应结转卡片（如免交增值税、地方水利基金、印花税、结转未分配利润）逐项执行
4. 查看资产负债表/利润表/现金流量表确认无误（账簿页可按月/年度/区间核对试算平衡）
5. 结账（如有误可先反结账/反结转，凭证亦可作废或删除）
